WARDRIVE GO WATCH

WardriveESP with watch support, for the Waveshare ESP32-S3 Touch AMOLED 2.06. Install it from this page, then pair it with the Wardrive Go app.

1. Install

This browser can't flash devices. Use Chrome or Edge on a desktop computer (Web Serial). Web Serial needs a secure page: open this site over https.
  1. Plug the watch into this computer with a USB-C data cable.
  2. Click Connect and install and pick the watch's port: USB JTAG/serial debug unit (/dev/ttyACM0 on Linux, a COM port on Windows).
  3. Choose Install. On the first install, tick Erase device: that removes Waveshare's factory demo. For an update, leave it unticked to keep your brightness and screen-off settings.
  4. Wait for Installation complete. The watch restarts on its own and shows the clock face.

If the port doesn't appear, the cable may be charge-only. On Linux your user needs access to the port (usually the dialout group).

2. Pair with Wardrive Go

  1. Turn Bluetooth on and open Wardrive Go (Google Play · App Store). Keep it in the foreground.
  2. The watch advertises as WardriveESP-XXXX. There's no pairing in the phone's Bluetooth settings: the app finds it and links by itself.
  3. On the watch, swipe to the dashboard: the status pill shows BLE and your phone's name, and SCAN WIFI reads ON.

3. Set the clock once

A new watch's clock face reads NO TIME YET, because Wardrive Go doesn't send the time. Set it once from a computer: see the user guide. The watch's clock chip keeps it after that, through restarts, updates and even a full erase (the chip is separate from the flash).

Don't update the watch from the app or the rocketgod.dev flasher

They install the published ESP32-S3 image, which doesn't drive the watch's screen. If that happens, install again from this page.
